# Knowledge Graph

**Save behavior:** By default both scripts write the output **after each item/instance** (`--save_every 1`). Use `--save_every N` to write every N completions (e.g. `--save_every 10` to reduce I/O). Use `--resume` to continue after interruption (load existing output and skip already-processed items).

```shell
conda activate KG_Agent
chmod +x ./scripts
./scripts
```
